A modern, highly interactive personal portfolio and blog built with **React**, **Vite**, and **Tailwind CSS**. It features a custom design system with rich glassmorphism aesthetics, a macOS-style terminal emulator, and an integrated markdown blog.

## ✨ Features

- **Terminal Emulator**: An authentic macOS-style terminal hero section with dynamic typing and CSS CRT effects.
- **Glassmorphism UI**: Beautiful, tactile interactive cards and buttons with glowing hover and active states.
- **Dark/Light Mode**: Full dual-palette theming with seamless dynamic transitions.
- **Markdown Blog**: Built-in MDX rendering for writing and hosting articles locally.
- **Accessibility (A11y)**: Fully semantic HTML structure, ARIA landmarks, focus rings, and skip links.
- **Performance Optimized**: Achieves near-instant LCP via smart font and image preloading strategies.

## 🚀 Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- `npm` or `pnpm`

### Installation

1. Clone the repository:

```bash
git clone https://github.com/hazem-alabiad/hazem-alabiad.github.io.git
cd hazem-alabiad.github.io
```

2. Install dependencies (strictly use `pnpm`):

```bash
pnpm install
```

3. Start the development server:

```bash
pnpm run dev
```

### Running Tests

The project uses [Vitest](https://vitest.dev/) and React Testing Library for unit testing.

```bash
pnpm run test
```
